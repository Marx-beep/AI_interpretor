# AI+口译

中英双向口译训练台，基于 Electron 构建，支持媒体上传、语音转写、源语重述、双向翻译、口译录入与自动评分，适合个人练习、课堂演示和口译训练场景。

## 项目简介

这个项目的目标是把一套口译训练流程放进一个本地桌面工具里：

- 上传音频或视频材料
- 自动转写源语内容
- 生成源语重述
- 生成机器参考译文
- 录入口译结果
- 自动给出对比与评分

整体设计偏实用，不依赖复杂部署，适合直接下载后在本机运行。

## 当前能力

- 上传媒体：支持 `mp3`、`mp4`、`m4a`、`wav`、`webm` 等常见格式
- 源语重述：先做语音转写，再生成同语种重述，不改变原语言
- 双向翻译：根据识别结果自动执行中译英或英译中
- 个人口译：支持麦克风录入口译文本
- 自动评分：将个人口译与机器参考译文做相似度对比
- 防作弊模式：录音结束前隐藏参考答案与评分
- 本地转写兜底：当云端 `/audio/transcriptions` 不可用时，自动切换本地 Python ASR

## 使用场景

- 个人中英口译训练
- 课堂口译演示
- 口语转述与复述练习
- AI 辅助对照学习

## 模型与 API 配置

当前版本支持“供应商预设 + 单一 API Key + 统一模型”配置方式。

可选供应商包括：

- `OpenAI`
- `DeepSeek`
- `阿里云百炼 (DashScope)`
- `OpenRouter`
- `自定义 OpenAI 兼容接口`

配置项说明：

- `API Base URL`：可自动填充，也可手动修改
- `API Key`：全流程共用同一个 Key
- `统一模型`：转写、重述、翻译均使用同一个模型名

注意事项：

- 不同供应商对 `/audio/transcriptions` 的兼容程度不同
- 如果远端不支持音频转写，项目会尝试走本地兜底转写
- 首次使用本地转写时，可能会自动安装 `faster-whisper`

## 防作弊流程

开启防作弊模式后，训练流程如下：

1. 上传并播放训练材料
2. 系统内部生成源语重述与机器参考译文
3. 录音结束前不展示标准答案与评分
4. 点击停止录音后统一展示结果、差异与得分

这个模式更适合课堂练习、限时训练和避免提前查看参考答案的场景。

## 一键启动

项目根目录提供一键启动脚本：

- `双击打开口译台.bat`

它会自动进入项目目录并执行 `npm start`。

## 开发启动

```bash
npm install
npm start
```

如果使用本地转写兜底，请确保本机有可用的 Python 环境。

## 打包

```bash
npm run dist
```

默认打包输出目录：

- `dist/`

## 项目结构

- `index.html`：界面结构
- `styles.css`：界面样式
- `app.js`：前端交互逻辑
- `main.js`：Electron 主进程与 API 代理
- `preload.js`：渲染进程与主进程桥接
- `local_asr.py`：本地 ASR 兜底逻辑
- `package.json`：依赖与启动配置

## 评分逻辑

当前评分是训练反馈型评分，不等同于正式口译评测。

主要参考：

- Token 集合相似度（Jaccard）
- 字符二元组相似度（Dice）
- 综合分数
- 遗漏与新增内容提示

## 已知限制

- 麦克风实时识别依赖浏览器 `SpeechRecognition / webkitSpeechRecognition`
- 不同系统与环境下，中英文实时识别效果可能有差异
- 部分 OpenAI 兼容接口仅支持文本模型，不支持音频转写
- 本地 ASR 首次加载可能较慢

## 安全提示

- API Key 会保存在本地存储中，仅当前设备可见
- 上传或公开仓库前，请确认没有把个人密钥写入源码或配置文件
